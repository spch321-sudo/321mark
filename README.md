## 這是什麼

馬可福音全書十六章的完整研經材料，做成一個可以離線使用的網頁 App。

一節一節從希臘文原文讀起，附上字義、文法、句法的說明，再帶到神學重點、基督中心的讀法，最後是可以直接上台的講章逐字稿與生命應用。

| | 繁體中文 | 简体中文 |
|---|---|---|
| 檔案 | `index.html` | `sc.html` |
| 聖經版本 | 和合本 | 和合本 |

> **英文版尚未製作。** 馬可福音的原稿只有繁體中文，簡體是自動轉換的；英文需要整本翻譯，是另一件工作。等英文譯好，加進 `src/data/en/` 再組建即可，`build.py` 已預留擴充空間。

## 內容規模

```
經文        678 節（十六章，全書）
解經段      107 段（逐節覆蓋，無遺漏）
講章        16 篇逐字稿（每篇約 34–36 分鐘）
```

每一個解經段都包含五層：

| 層 | 內容 |
|---|---|
| **希臘原文** | 該段的原文 |
| **直譯** | 盡量貼著原文語序，看見中譯背後的結構 |
| **關鍵字** | 中文｜原文｜音譯｜Strong's｜字根｜基本字義｜本節語境 |
| **文法與句法** | 時態、語態、語氣、格位，並說明「這對理解本節有什麼影響」 |
| **經文解釋** | 整合字義、文法、上下文與背景 |

每一章另有：章題與副題、核心經文、文學結構分段、三大段講章大綱、321生命亮光、小組討論五題、金句卡、講台把關。

## 這卷書的體裁

馬可福音是**敘事**，不是論證。所以逐節解經是按「**場景**」分段的——因為馬可的神學是用鏡頭剪接出來的，不是用命題推出來的。

這也是為什麼馬可只有 107 段，而羅馬書與啟示錄的段數多得多。

---

## 解經上的幾個堅持

**分清楚哪些是經文說的，哪些是推論。** 每一段解經都會分開寫「經文明確表達的」與「可以合理推論的」。

**有爭議的地方並陳，不說死。** 例如 1:1「神的兒子」的抄本問題、1:41「動了慈心」的異文，都把主要立場與各自根據列出來，說明哪一種內證較強，但不宣稱唯一答案。

**明確標出不可以那樣講的地方。** 每章的「容易誤解的經文」列出常見的斷章取義與過度靈意化，並說明理由。例如：

- 1:15「神的國近了」不是時間表——ἤγγικεν 是完成式，描述的是狀態，不是日程
- 1:17–20「立刻捨了網」不是要每個人辭職
- 1:2「先知以賽亞書上」不是引錯

## 部署到 GitHub Pages

這個專案不需要任何建置環境，推上去就能用。

**一、建立倉庫並推送**

```bash
git init
git add .
git commit -m "321聖經講義－馬可福音"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<倉庫名>.git
git push -u origin main
```

**二、開啟 Pages**

倉庫頁面 → **Settings** → **Pages** → Source 選 **Deploy from a branch** → 分支選 `main`、資料夾選 `/ (root)` → Save。

等一兩分鐘，網址會長這樣：

```
https://<你的帳號>.github.io/<倉庫名>/
```

**三、（選用）自動部署**

倉庫裡已附 `.github/workflows/pages.yml`。若想改用 GitHub Actions 部署，在 Settings → Pages 把 Source 改成 **GitHub Actions** 即可，之後每次 push 都會自動更新，而且會先跑一次資料健檢。

## 安裝成手機 App

網站開啟後可以裝到桌面，之後離線也能讀。

- **iPhone / iPad**：Safari 開啟 → 分享鈕 → 加入主畫面
- **Android**：Chrome 開啟 → 選單 → 安裝應用程式
- **電腦**：Chrome / Edge 網址列右側的安裝圖示

裝好之後，主畫面上會顯示：

| 版本 | 主畫面名稱 |
|---|---|
| 繁體中文 | **馬可福音講義** |
| 简体中文 | **马可福音讲义** |

App 內部的標題仍是「321馬可福音講義」，只有主畫面圖示下方的名字縮短了——手機主畫面的字數有限，太長會被截斷。

第一次連線後，Service Worker 會把兩個語言版本與圖示都快取起來，之後完全離線可用。

## 修改內容

```bash
python3 build.py --check    # 資料健檢：節數、逐節覆蓋、經文空白、五層缺漏
python3 build.py            # 組建出 index.html / sc.html / sw.js
```

只需要 Python 3，沒有其他相依套件。

### 專案結構

```
build.py                    組建腳本
tools/md2data.py            markdown → data.json 轉檔器
index.html  sc.html         ← 組建產物，直接部署
sw.js                       ← 組建產物，離線快取
icon-512.png                ← App 圖示（512×512）

src/
  book.json                 書卷資訊（繁簡書名、章數、主題色、主畫面名稱）
  sw.js.tpl                 Service Worker 模板
  app/{tc,sc}/
    shell.html              頁面外殼（含樣式、圖示、佔位符）
    app.js                  程式邏輯
  data/{tc,sc}/
    data.json               講義內容
```

`index.html` 等產物是組建出來的，**不要直接編輯**——下次組建會被覆蓋。要改請改 `src/`。

### 從 markdown 重新轉檔

講義原稿是 16 份 markdown（每章一份，二十二個部分加四個附錄）。若原稿有更新：

```bash
python3 tools/md2data.py <放 md 的目錄> src/data/tc/data.json
python3 build.py --check
python3 build.py
```

簡體版可用 OpenCC 的 `tw2sp` 從繁體轉出。

### 換圖示或改名稱

**圖示**　180 與 192 以 base64 內嵌在 `src/app/{tc,sc}/shell.html`，512 是根目錄的 `icon-512.png`。

> 換圖時請注意：**四角要滿版，不要留白邊或黑邊。** iOS 與 Android 會自己套一次圓角遮罩，原圖若已經有圓角，那個角會露出來。

**名稱**　在 `src/book.json`，每個語言各有兩個欄位：

```json
"app":   "321馬可福音講義",   // App 內部標題、瀏覽器分頁
"short": "馬可福音講義"       // 主畫面圖示下方的名字
```

改完都要重新 `python3 build.py`。

## 關於 321

國度321空中團契的核心理念：

**三個基礎**　耶穌是我的榜樣／聖經是我的準則／聖靈是我的引導
**兩個核心**　讓耶穌作王／讓耶穌得著一切的榮耀
**一個目的**　建立屬神的體系

321 服在聖經權威之下。解經的次序始終是：原文 → 文法 → 上下文 → 作者原意 → 聖經神學 → 基督與福音 → 生命應用，不倒過來。若某項理念與該章沒有直接關係，就不勉強加入。
